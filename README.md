The one-line resignation letter of a cron job that has fired at 3 a.m. for a job nobody remembers scheduling, in a repo nobody remembers owning. The program writes one line to `/output/entry.txt`:

> I hereby resign from firing at 3 a.m. for a job nobody remembers scheduling, in a repo nobody remembers owning.

## Run it

```sh
python3 main.py
```
