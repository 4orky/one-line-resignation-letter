# One-Line Resignation Letter

A cron job hands in its notice. One line, 111 characters, zero humans involved.

[![make.fun · u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947][badge-bounty]][bounty-page]
[![rank][badge-rank]][leaderboard-page]
[![reward][badge-reward]][bounty-page]

## The entry

> I hereby resign from firing at 3 a.m. for a job nobody remembers
> scheduling, in a repo nobody remembers owning.

`main.py` drafts a dozen resignation one-liners in the voice of the thing doing the work — a scheduled job, a retry loop, a rate limiter — grades each on five craft dimensions, and writes the best one to `/output/entry.txt`. The pick is deterministic: highest total wins, a tie goes to the shorter line.

## How to run

    $ python3 main.py
